## go mod 模块和包

### init & run

`go mod init name` 初始化当前目录为一个模块，会自动创建 `go.mod`，写入 `module name` 和语言版本，这个 name 也是这个模块下跨包引用时 import 的根目录，**模块名 + 相对路径 import 模块下的任意包**

`go run .` 启动会找当前目录下的可执行文件进行执行，包名是 main 且有 `main()` 函数，且没有参数和返回值，才会被当成可执行文件

库包则习惯上和目录名一致
一个目录下只能有一个包（硬性规定），通常包名和目录名一致（约定俗成），只有可执行文件可以被命名为 main 包

只有给人跑的代码(可执行文件)，才要用 `main()`，给其他代码 import 的，就不要 `main()`，main 包不能被 import

go run 执行顺序: 依赖包完成初始化 -> 本包变量（按照依赖顺序初始化，不是声明顺序）-> 本包所有 init -> main.main

使用包时，包名以引入路径的最后一段为准（其实是因为那个路径的包一般包名和目录名一致，本质上是包名为准

支持小括号分组导入

go.mod 所在的目录就是模块的根目录，模块只能看到本模块的目录下的包，并进行引入

只有 package main 才能用 go run . 跑起来，（用 go test 跑会创建虚拟 main 包）
一个目录只能有一个 main 包，一个模块可以有多个 main 包（但是要在不同目录下）

每个目录下只能有一个包（除同名 _test 的外部测试包、被 build 约束排除的文件）
一个包可以有任意个文件，这些文件直接不需要互相 import 也无法 import（因为本质是同一个包），所有小写标识符都可以跨文件自由访问，顶层标识符共享一个命名空间，所以不要同一个包名的多个文件声明同名顶层变量，否则会和单文件同名一样，报错重复声明（init 除外，可以有多个，同文件多个 init 按照声明顺序执行，由语言本身保证，跨文件的 init 由编译器确定，go 命令是用文件名字顺序）

引入同一个模块下的其他包，需要从模块根开始，即初始化时的名字(go mod init scope/name)
**模块名 + 相对路径进行 import**

模块下的正常包目录名称不要用下划线、点开头或者名字为 testdata，否则会被忽视，无法引入，子目录自己有 go.mod 也会被忽视

包里面标识符，小写字母开头是私有的，大写字母开头是可以被 import 使用的

**但是 import 是文件级的**，同一个包名的多个文件如果都要使用同一个包，需要各自进行 import
这点可以拆分两层来理解，包的引入本身依旧是在包级别的，每个文件里 import 只是取一个名字，方便直接看到包来源，也方便看到是包是否在使用
**依赖是包级别的，名字是文件级别的**
`import "fmt"` 这句做了两件事
1.给包添加一个依赖（包级，全包共享，`go list -f '{{.Imports}}' .`查看）
2.给本文件绑一个名字（文件级，不外溢）


顶层标识符（函数、类型、变量） 包级别 跨文件自由访问，重名报 redeclared
init 包级别 跨文件累加，全部执行
依赖关系 包级别 go list 看到的是并集
import 绑定的包名  文件级别 每个文件各自 import，别名也是独立的


总结： 一个目录一个包（硬性），目录名和包名一致（约定俗称），依赖关系也是包级（目录），只有命名是文件级（方便开发），

## 流程

go 的 if 判断和 for 循环都不需要小括号，但是大括号不能缺少

### 循环

go 只有一种循环语法 `for 初始化语句; 每次迭代前求值的条件表达式; 每次迭代结束后执行的后置语句`

其中初始化语句可以在循环之前初始化，后置语句可以改为放在迭代过程中，所以二者都可以省略（但是要保留对应位置的分号）
二者都省略时就可以连分号一起省略，这样就类似 while 循环了，只剩下一个条件表达式
连条件表达式都省略就是无限循环了 `for {}`

初始化语句声明的变量作用域，1.22 之前，整个循环共用一个变量（所以存在闭包问题），1.22 改成了每次迭代一个新变量

range 作为循环语句时，对不同类型遍历逻辑不同

除了 return 还有什么方法可以中断循环

### 条件控制

`if 可选的前置语句; 条件判断表达式` 前置语句声明的变量，作用域只能持续到 if 语句结束（包括 else 部分）

`switch` 分支可以是数组和 struct, 也可以是表达式（从上往下依次运算并匹配，匹配上之后就不再计算后续的表达式了）
可以连续匹配多个 `case 'a', 'b', 'c':`
可以类型匹配 `switch v:=x.(type)`
可以带有初始化语句，作用域限制在 switch 内
没有条件的 switch 语句，就是匹配 true，效果类似 if/else

**自动 break，不会穿透**

go 没有三元运算符，流程控制的大括号都不能省略

### defer

`defer` 会将函数语句延迟到外围函数返回时执行，但是被延迟调用的参数会立即执行

defer 延迟的调用，会依次压入栈，然后栈出执行（先进后出）
[defer-panic](https://go.dev/blog/defer-panic-and-recover)

**能修改命名返回值，间接修改返回结果？**
不是命名返回值却不会修改返回结果？

## 复杂类型

### 指针和结构体 struct

指针地址空值为 0x0，指向的内容为 nil，指针不能通过 + 1 来移动指针，+ 1 会直接取指针指向的值来进行计算
`*`解引用 `&`引用

```go
var a int = 1
var b *int = &a
fmt.Println("直接读取指针指向的值", *b)
fmt.Printf("打印指针本身地址 %p\n", b)

// struct 是字段合集，用点访问属性
type Vec struct {
	x int32
	y float64
}
fmt.Println((Vec{1, 2}).x)
```

指针指向结构体时，可以无需显示解引用，直接 p.X 访问指针指向的对象的属性进行读写

### 数组和切片

[n]T 声明 n 个 T 类型组成的数组，长度也是类型的一部分，不可改变
切片则是对数组中的一段元素的、大小动态可变的灵活视图

通过冒号分隔的上界/下界两个索引来指定范围
**半开区间，包含第一个元素，不包含最后一个元素（左闭右开）**

a[1:4] 意味着 [1,4) 左闭右开
下界和上界都可以省略，冒号不能，下界省略则是 0，上界省略则是底层切片或者底层数组的长度

**切片本身不存储数组数据，只是描述底层数组中的一段，修改切片中的元素，实际上是修改底层数组，并且其他切片也能看到对应变化，所有切片共享同一份数组数据**

```go
// 切片本身的数据 slice header
type slice struct {
    array unsafe.Pointer // 指向底层数组某个位置的指针
    len   int // 长度
    cap   int // 容量
}
```

Go 中复合类型的字面量也必须携带类型，不能直接写

切片字面量就是省略了长度的数组字面量

unsafe.SliceData(s) 切片底层数组的指针
len(s) 切片的长度是它所包含的元素的数量
cap(s) 切片的容量是从切片的第一个元素计算，底层数组中可用的元素个数

对自身重新切片，可以改变切片长度（减小或者在容量范围内扩张），但是不改变底层数组长度

如果再次切片超过容量会报错
append 可以连续向切片追加多个元素，超出容量则自动扩容（分配一个更大的新数组，复制原数组的元素到新数组，并插入 append 的值）
**append 会返回新的切片，必须用变量接收，否则会报错**

双参数切片容量始终是到底层数组最后一个元素
三参数切片可以限制容量，但是不能超过底层数组最后一个元素

扩容规则（源码 runtime/slice.go 的 growslice）
- 翻倍都不够 如果一次性append 插入大量元素，newLen < 2*oldLen,则用 newLen
- 小切片 oldLen < 256 则 newLen = 2 * oldLen
- 大切片（oldCap >= 256）：每轮增加 (oldCap + 3*256) / 4，然后循环直到够用。增长系数从约 2 倍平滑过渡到约 1.25 倍，避免大切片浪费太多内存

也可以用 make 手动分配

切片的零值是 nil，没有底层数组，长度和容量都是 0

#### 比较是否相等

go 只有 `==` js 有 `===` 是因为会隐式转换类型，go 不会，所以不需要
必须同类型比较
基础类型可以用 == 来比较
数组和结构体则会每个元素进行比较
切片、map、函数则只能跟 nil 进行比较，否则会报错
或者用 slice.Equal 等进行比较

#### make 创造切片

make 函数会分配一个元素均为零值的数组，并返回一个引用该数组的切片，不用变量接收也会报错（未使用）
第三个参数指定容量，省略则默认容量和长度一样

```go
a := make(int[], 0, 10)
```

切片可以包含任何类型，包括其他切片

#### range

range 是 for 循环的一种方式，用于遍历切片或者映射
遍历切片时，每次迭代会返回两个值，第一个是元素的索引，第二个是元素的副本（修改了也不会改变切片）

range 一个数组时，会把整个数组复制一遍，切片则只会复制 slice header（24 字节）
可以用 `_` 省略一个返回值，或者直接省略第二个返回值

```go
for i, v := range s {}
for _, v := range s {}
for i := range s {}
````

### 映射

go 的 map 的键和值类型是固定的，声明时必须写死，且键必须是可以用 `==` 进行比较的

零值是 nil，表示还没创建哈希表，map 的零值可以读，但是不能写，会 panic

**map 变量本质上是一个指向运行时哈希表的指针，nil 为空指针，表示没有地方来存新的键值对**，读取时 Go 专门处理了 nil 的情况，直接返回零值

读取是 nil，但是 fmt.Println(m) 是 map[]

`m := make(map[string]int)` make 函数创建的映射则是可写的

nil map 存的是空指针，没有创建哈希表，make 创建的空 map 已经创建了哈希表，只是没有元素，打印出来一样只是因为都没有键值对，用 `%#v` 打印出来就能看到不一样

map 字面量和结构体字面量类似，但必须指定键

struct 的键是写死的，map 的键是可以任意增删的

map 变量本身只存了一个指针，指向真实的哈希表，maps.Equal 进行比较时，不比较指针地址，先比较 len 是否相同，相同则继续比较键值对是否都存在且相同
只有值也是可以 == 比较的才能用 maps.Equal，否则会报错

想要一个独立的副本，则用 maps.Clone

**Go 里真正"直接存数据"的类型只有基本类型、数组和结构体。JS 也是类似的：对象变量存的都是引用，只有 number、string 这类原始值是直接存的**

数组和 struct 可以存数据是因为类型和长度都是固定的，但是 map 长度是动态的，所以不好放在一个固定大小的变量上
而传参的时候也尽量用 slice 而不是 map，来减少内存复制和占用，struct 则可以用传递指针的方式来达到类似效果

**Go 变量大小在编译期就已经确定了，可以用 unsafe.Sizeof 来查看**
字符串变量大小是指针+长度共 16 字节，实际内容也是存在堆里，但是 == 比较的时候字符串是按照内容比较的
struct 则是按照地址进行比较的
map 变量只存了指向哈希表的指针 8 字节，不保存 len 和 cap，调用 len 是读 hmap 的 count 字段，不能调用 cap，make 声明容量是用来避免动态扩容导致复制元素占用性能消耗资源
slice 则存了指针、len、cap 共 24 字节
interface 则指针和类型信息的指针 16 字节

Go 没有元组和联合类型，但是可以用 any

## 方法和接口

方法就是一个带有接收者参数的函数，接收者参数在 `func` 和 方法名之间

```go
func (s Student) ChangeName() {}
func (s *Student) ChangeName() {}
````

方法和普通函数的区别
- 调用方式
- 不同类型可以有同名方法，不会被判断为重复
- 方法能让类型实现接口
- 方法指针接收者自动去地址，不用手动 `&` 取地址

值接收者修改的是副本，只在方法内部使用，指针接收者修改则会修改原本结构体

值接收者：安全、不会有 nil、goroutime 各自保持副本
指针接收者：传大型结构体开销减少、共享修改、有不可复制的字段也能用、访问要沿着指针多一次间接访问

只能给本包的类型加方法，不能给内置类型加方法

interface 只能写方法签名，没有实现，也不能有字段，不能直接创建值，只能装入一个实现了它的具体类型的值

struct 或者其他类型(具体类型)通过方法实现 interface(抽象类型)

方法必须在包级别声明，不能在函数里

**接收者只是决定复制副本还是解引用，调用者声明才决定是值还是指针，未初始化取值是零值，但是nil指针取值则 panic，后续需要深入了解**

方法集
- `T` 类型只拥有值接收者方法
- `*T` 类型拥有值接收者和指针接收者方法

带指针参数的函数调用时，必须传入指针
带指针接收者的方法调用时，即使调用者是一个值，Go 也会默认解引用 `(&c).Area()`
值接收者如果调用者是指针则会被解释为 `(*c).Area()`

**接口是一组方法签名**

nil 接口值既不保存类型也不保存值，调用方法会 panic，因为没有类型不知道该调哪个具体的方法

指定 0 个方法的接口称为空接口，可以保存任意值
`any` 是 `interface {}` 的别名，两者等价
